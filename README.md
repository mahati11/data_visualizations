# Los Angeles Crime Analysis Dashboard

An interactive **Tableau dashboard** analyzing crime patterns in Los Angeles.

### 📊 Dashboard Analysis

* Crime trends by day and hour
* Geographic crime density
* Victim demographics by age and sex
* Victim ethnicity
* Top crime types
* Weapon usage

### 🛠️ Tools

* Tableau
* Kaggle Dataset
* GitHub

### 📂 Dataset

[Crimes in Los Angeles — Kaggle](https://www.kaggle.com/datasets/sudhanvahg/crimes-in-las-angeles/code)
